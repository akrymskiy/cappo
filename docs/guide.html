Guide

Everything CapPo shows you, and what it means.

Most of the time there's nothing to do. CapPo sits in the notification area, and when a network wants you to sign in, its sign-in window opens by itself. This page is for everything else.

Before you start

CapPo works with Windows' own encrypted DNS. Set it up for all Wi-Fi networks, so networks you haven't joined yet use it too, and with the fallback to plain DNS turned off. In Windows 11:

  1. Open Settings > Network & internet > Wi-Fi > Hardware properties. (For a cable, open Ethernet instead.)
  2. Next to DNS server assignment, choose Edit, then Manual, and turn on IPv4.
  3. In Preferred DNS, type your provider's address. Set DNS over HTTPS to On (manual template), type your provider's template, and set Fallback to plaintext to Off.
  4. Do the same for Alternate DNS, and for IPv6 if your provider has IPv6 addresses.
  5. Choose Save.

Your provider's setup page has the addresses and the template. NextDNS, for example, shows them filled in for your account under Setup at my.nextdns.io.

Then open CapPo's DNS page: it should say Encrypted only, on every Wi-Fi network. Windows 10 has no setting for this, so these steps are for Windows 11.

The icon in the notification area

The icon is a fedora over a Wi-Fi signal. Point at it to see the network's status. If you don't see it, it may be hidden behind the arrow next to the clock: drag it out, or turn it on in Settings > Personalization > Taskbar > Other system tray icons.

The iconStatusWhat it means
Hat and Wi-FiOnlineThe internet works. Your DNS stays encrypted.
A feather in the hatSign-in neededThe network wants you to sign in. Click the icon to open the sign-in window.
Wi-Fi arc fadedNo internetConnected, but nothing answers, not even a sign-in page.
All fadedNot connectedNo network, or CapPo hasn't checked yet.

Click the icon to open the sign-in window when a network is waiting for you, or CapPo's window otherwise. Right-click it for the menu:

  • Sign in… (only when a network wants you to sign in) opens the sign-in window.
  • Check now checks the network right away and tells you what it found in a notification.
  • Settings and About CapPo open CapPo's window.
  • Exit closes CapPo. In On demand mode, Windows still starts it when it's needed.

Signing in

When CapPo finds a sign-in page, it opens it in its own window, called Sign in to and the network's name. Only this window uses the network's DNS. Sign in as you would in a browser: accept the terms, type the room number, whatever the network asks.

  • At the top: Back, Reload, and the address of the page you're on, with a lock when it's HTTPS. Check the address before you type a password or a card number, as you would anywhere.
  • Under the address, what CapPo is doing: it checks every few seconds whether you're through.
  • Start over opens the page that brings up the network's sign-in page again, if you got lost or the page stopped working.

Once you're online, the window says You're online and closes by itself, and a notification says which network you're signed in to. CapPo also clears Windows' DNS cache, which still holds the lookups that failed before you signed in.

If you close the window yourself, it stays closed until something changes, such as another network. To open it again, click CapPo's icon.

Many portals sign you out after a while. CapPo checks again every so often (see Re-check interval), and opens the sign-in window again when that happens.

Settings

At the top, the network's status as CapPo sees it, when it last checked, and Check now. When a network wants you to sign in, there's a Sign in button too.

How CapPo runs

  • Always running (the default): CapPo stays in the notification area and notices network changes the moment they happen.
  • On demand: CapPo doesn't stay running. Windows starts it when a network connects and then every so often (the re-check interval), for a check that takes about a second. It only shows up when there's a sign-in page, and then it stays until you're online. After you switch to On demand, CapPo stays open until you exit it; from then on, it starts by itself when it's needed.

On demand uses Windows' own tools to start CapPo: a Task Scheduler task in the GitHub version, and a background task in the Microsoft Store version. Neither needs administrator rights.

Launch at login

In Always running mode, starts CapPo in the notification area when you sign in to Windows. It's on by default. If you turned CapPo off in Task Manager's Startup apps, Settings says so, and you turn it back on there. In On demand mode this setting isn't needed, since Windows starts CapPo when a network connects.

Re-check interval

How often CapPo checks again while you're online, for portals that sign you out when a session runs out: every 5, 15, 20 (the default), 30 or 60 minutes. The Microsoft Store version starts at 15 minutes, the shortest that Windows allows for a Store app's background task.

The DNS page

The DNS page shows how Windows looks up names on the connection your internet traffic goes through. It only reads Windows' settings; to change them, use Windows settings on the page, which opens the right page of Windows' Settings.

The DNS page saysWhat it means
Encrypted onlyWindows looks up every name with encrypted DNS and never falls back to plain DNS. Sign-in pages can't open by themselves, so this is where CapPo is needed. When the page adds "On every Wi-Fi network, including ones you haven't joined yet", new networks are covered too.
Encrypted, with fallbackWhen an encrypted lookup fails, as it does behind a sign-in page, Windows asks the same server again in plain DNS. Those lookups aren't private, and many sign-in pages still don't open. Turn the fallback off, and let CapPo handle sign-in pages.
Not encryptedWindows uses plain DNS here. Sign-in pages open by themselves, but your lookups aren't private.
Not encrypted by WindowsA VPN carries your traffic, and its DNS is plain, but it travels inside the VPN.
Encrypted DNS is turned offYour organization's Group Policy doesn't allow encrypted DNS on this PC.

Below that, for each network connection:

  • its DNS servers, and whether each one is encrypted only, falls back to plain DNS, or is plain DNS;
  • where the servers come from: typed in for all Wi-Fi networks, typed in for this Wi-Fi network only (a network you join for the first time then uses its own DNS, unencrypted), typed in for this connection, or handed out by the network (DHCP);
  • which connection is a VPN, and which one carries your internet traffic.

If your organization sets encrypted DNS by Group Policy, the page says whether it's required or allowed. Under Names sent to other servers (only shown when there are such rules), it lists rules that send some names to particular DNS servers (Windows' Name Resolution Policy Table), set by Group Policy, a VPN or another app. Lookups for those names don't use your encrypted DNS.

VPNs

CapPo notices when a VPN carries your traffic. Its status then says Online through a VPN, with the VPN's name, or No internet through the VPN when nothing answers through it.

A VPN can't connect until you've signed in to the network, and a VPN that blocks traffic outside the tunnel (a "kill switch") blocks the sign-in window too. If you're stuck, turn the VPN off, sign in, and turn it back on. CapPo says so when it sees this happen.

About

About CapPo shows the version and which one you have (Microsoft Store or GitHub), links to this site and the source code, and Open CapPo's folder, which holds its settings and its log, cappo.log. The log stays on your PC; it's useful when you report a problem.

The Microsoft Store version's trial

The Microsoft Store version comes with a 30-day trial. Settings shows how many days are left. When the trial ends, CapPo keeps showing the network's status, but it no longer opens sign-in pages, and the icon stays faded. Buy it from Buy CapPo in Settings or in the icon's menu. The GitHub version has no trial and no limits.

The GitHub version

  • The first time you run it, CapPo adds itself to the Start menu.
  • Its settings and log are in %LocalAppData%\CapPo.
  • Launch at login uses your user's startup entry; On demand uses a Task Scheduler task named CapPo portal check and your user name.
  • If you move CapPo's folder, run it once from the new place, so its Start menu shortcut, startup entry and task point there.
  • To remove it, run CapPo.exe --unregister, then delete the folder and %LocalAppData%\CapPo.
