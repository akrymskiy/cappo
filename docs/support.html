Common questions

The network wants me to sign in, but I don't see CapPo's window.
Click CapPo's icon in the notification area, or right-click it and choose Sign in…. To make CapPo look again right away, choose Check now.
Windows opened a browser too, and it shows an error.
That browser uses your encrypted DNS, which the network blocks until you sign in, so it can't load the page. Close it and sign in in CapPo's window.
I use a VPN.
Turn the VPN off to sign in, then turn it back on. While a VPN carries all your traffic, CapPo can't reach the network's sign-in page, and a VPN's "block untunneled traffic" setting blocks CapPo's sign-in window too.
Does CapPo change my DNS settings?
No. Only CapPo's sign-in window uses the network's own DNS. Everything else keeps using your encrypted DNS, and CapPo never changes Windows' settings.
How do I uninstall it?
Microsoft Store version: uninstall it like any app, from Start or Settings > Apps.
GitHub version: run CapPo.exe --unregister (it removes CapPo's Start menu shortcut, startup entry and scheduled task), then delete CapPo's folder and %LocalAppData%\CapPo.

Report a problem

Open an issue on GitHub. Portals come in all shapes, so the details help most:

  • Where you were: the kind of place (hotel, airport, library, café, a flight), and the chain or Wi-Fi provider if you know it.
  • What happened: what CapPo's icon said, whether the sign-in window opened, and what it showed.
  • Versions: CapPo's version and build (Microsoft Store or GitHub), from About CapPo, and your Windows version.
  • CapPo's log, cappo.log: in About CapPo, choose Open CapPo's folder.

Issues on GitHub are public. The log lists network names, adapter names, DNS server addresses and sign-in page addresses, so look it over first and remove anything you'd rather not share.
